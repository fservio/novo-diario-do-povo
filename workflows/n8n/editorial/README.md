# Workflows editoriais em produção

Os arquivos JSON registram as versões ativas consultadas no n8n. Cada arquivo conserva o ID do workflow, o ID da versão ativa, os nós, as conexões e as configurações visíveis pelo MCP.

A restauração em outra instância requer vincular as credenciais no n8n e remapear os IDs de subworkflows. Os dados de execução e os workflows temporários usados nos testes ficam na instância de origem.
